# LAST LIGHT

A browser-based first-person arena shooter built with Three.js. Defeat the training bot, manage your health and ammunition, and survive the match.

## Run

Serve this folder with a local web server, then open it in a browser. For example, run `python -m http.server` and visit `http://localhost:8000`. An internet connection is needed to load Three.js and the fonts.

## Controls

- Arrow keys: move and turn
- Space: fire
- R: reload
